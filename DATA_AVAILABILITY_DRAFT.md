# Data Availability Statement (draft)

The submission archive may include anonymised device identifiers, the derived DI/HI
trajectories, endpoint/lifetime labels, frozen device-wise folds, configuration
files, prediction-level outputs, statistical results, and figure-generation code.
Raw proprietary voltage/current records, direct device/batch identifiers, and the
detailed proprietary DI-construction procedure will not be released. Public-data
source locations and processing code will be provided so those experiments can be
reproduced from the original public datasets.
