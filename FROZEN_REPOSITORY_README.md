# D2Pred frozen experiment code

This repository contains the code, configurations, manifests, tests, and public-data processing utilities used by the prespecified D2Pred evaluation protocol. Large generated outputs, private/processed data, model checkpoints, and runtime caches are intentionally excluded from version control.

The corresponding prediction-level outputs and checksum records remain in the working archive and are referenced by the manifests. The AC DI construction remains proprietary; only the documented high-level interface is included.
